Při uložení ceníku správce zadá jméno nebo přezdívku. Historie změn je chráněna správcovským heslem a ukládá čas, verzi, změněné položky a původní/nové hodnoty. Jméno je vlastní prohlášení, protože aplikace používá společné heslo, nikoli osobní účty. Historie začíná po nasazení této verze.

V DPV a Odemčení vozidla se účtuje práce mechanika po každých započatých 30 minutách, sazby jsou oddělené a výchozí jsou nulové. Zahraničí CZ/SK má ruční paušál nebo hodinovou sazbu a cenu za kilometr; výchozí ruční sazby jsou nulové. Aplikace obsahuje také přehledný UZ a doplatek klientovi zobrazuje pouze při kladné částce.

Kalkulačka je veřejná a úprava ceníku chráněná heslem. Balíčky neobsahují produkční databázi, hesla, tokeny ani adresy serveru.
